## Self-service recovery

1. Quit JARVIS and open it again.
2. Check Settings → Permissions and Settings → Voice.
3. Disconnect and reconnect an optional account integration.
4. Use Settings → Privacy & Reset only if the customer accepts that local
   JARVIS data will be deleted.
