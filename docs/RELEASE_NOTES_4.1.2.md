# JARVIS v4.1.2 for Windows

JARVIS v4.1.2 is a Windows x64 release focused on fast bilingual conversation,
simple setup and predictable local CPU use.

## Highlights

- OpenAI GPT-5.4 Nano is the default cloud intelligence; Claude, Kimi, Qwen,
  Gemini, Grok and trusted compatible cloud endpoints remain optional.
- German/English microphone recognition and the selected bilingual JARVIS
  voice run locally on the CPU. No CUDA-compatible GPU is required.
- “Hey JARVIS” starts after the one-time microphone permission step and remains
  enabled across restarts unless the user turns it off.
- Settings use compact icon tabs, recognizable Gmail/Calendar/Outlook icons and
  direct account-consent actions.
- Clear, reversible local tasks start immediately. Destructive, financial,
  publishing and account-changing actions still require explicit instruction.
- Public ticket pages can be summarized through the read-only website reader;
  it cannot click, submit forms, upload files or use browser cookies.
- The Windows title-bar layout keeps microphone and settings controls clear of
  minimize, maximize and close buttons.
- The assisted installer preserves settings during upgrades, enforces one app
  instance, and removes private app data during uninstall.

The customer download is one signed file: `JARVIS-v4-4.1.2-x64.exe`.
